2026-10-29。用户明确要求改成YAZIO式体验：中间内容跟随手指移动、拖动时露出相邻日期、松手吸附或回弹，顶部/底部固定。本次在未提交的短距离方案上继续修改；正式代码基线c3df03da6578a5e135fc60bfaa23d85e1bafd744，正式2.4.3和短距试用包均保留。

## 实现

- 中间使用PageView.builder按日期分页，拖动时移动真实页面，可同时看到两天的真实营养汇总与四餐内容，没有透明叠加旧文字。顶栏、日期栏位置、底部导航不移动，日期文字随占主要位置的页面更新。
- 用原有受保护的横向手势驱动PageController的位置，保留系统边缘及横纵方向判别。关闭PageView自行吸附以避免手指停住时页面自行动；松手时按距离和同向速度选择相邻一天或原页，250ms吸附。每次拖动最多跨一天，首末日期保持原边界。
- 左右箭头、日期选择、回今天共用同一分页控制器；远日期跳转直接定位，不遍历中间数千页。系统关闭动画时按钮直接定位，直接手势仍按手指移动。
- 日数据按日期独立缓存；预读邻近日，清理距离当前日超过两天的缓存。逐日纵向滚动位置独立保存，不一次实例化所有日期。
- CalendarDayBloc.loadDaySnapshot复用原读取/营养计算逻辑，只返回带日期的快照，不改变所选日期、请求代次或Bloc状态。已沿TrackedDayRepository/TrackedDayDataSource核对读取路径，不新增摄入或日期记录。
- 当前餐次详情仍使用原活动Bloc；切页中、非当前页及活动日期尚在加载时不允许误点餐次/添加操作。每页回调捕获自己的日期，活动请求沿用代次乱序保护。
- 从添加、食品库、设置和详情返回及后台恢复时重新读取当前日并清理相邻日旧预览，避免重复显示过期数据。只读首页的键盘布局保护保留。
