# 界面备注文字审核清单

2026-10-28初审；2026-10-29用户已同意建议并执行。下表保留审核时的原文及逐项理由，落实情况见 `UI_FOOD_LIST_AND_COPY_IMPLEMENTATION_20261029.md`。左右换日、移除下拉刷新和单位宽度另行实施。

## 已确认原则

- 删除重复的功能介绍：简单/详细模式介绍、本地资料下“无需身体信息”、空结果页对现有按钮的重复解释。
- 缩短仍有用的提示：营养基准、录入/显示单位、改记录不改食品、另存食品、备份/CSV/恢复规则。
- 正常页面不常驻长段计算口径和来源声明，完整内容移入对应说明；来源信息不直接丢弃。
- 保留未知与0的区别、每100g/ml等数值基准、即时单位换算、异常核对、破坏性操作确认、恢复冲突、隐私外发/费用说明。
- 趋势说明继续默认折叠；空页和异常态提示只在对应状态显示。
