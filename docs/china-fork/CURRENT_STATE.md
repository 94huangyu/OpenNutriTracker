## 第三版状态与用户纠正

- 用户指出第二版在基准为“份”时隐藏重量编辑、输入和下拉外观不齐；这是原型缺陷，不归因用户显示。
- 简单模式始终显示每份名称、1份对应多少g/mL、每份单位。每份营养与每份重量独立；0.5份=75g、1.5份=225g可双向记录。
- 15项原型计算、72条 Chromium 浏览器检查通过；24种布局共30组同排控件测得高度和顶部差值均0，外观均none；内置浏览器390px也核对了创建/详情控件48px等高和半份换算。

- 首页四餐默认只显示餐次名称、总热量和添加入口，点餐次展开明细后仍能改量、删除、重复记录。
