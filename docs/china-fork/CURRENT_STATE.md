## 最新产品范围修订（2026-10-15）

用户真机首次设置时明确要求：“原始app前面那些设置都不要，我不要用它来管理身材，只是记录摄入情况，所以不要多余记录我的信息，包括每天记录运动情况也不要。”

此决定覆盖早先的体型管理需求：新装不要求性别、生日、身高、体重、活动水平或体重目标；不提供每日运动记录/消耗抵扣。首页以实际摄入热量和营养汇总为主，移除身体资料推导的目标/剩余热量展示。现有食品与日记保留，不静默删除历史身体/运动资料。原UserDBO的多项身体字段为非空，不能用编造的身体数据绕过首次设置；本轮已调整入口和依赖，并用空UserDBO真实临时Hive验证首次记录和重开。

M2.1旧测试包含原首次设置和运动入口；本轮M2.2已覆盖安装记录模式测试包，原历史身体/运动资料保留而不再要求或展示，不继续构建体型/运动管理功能。
