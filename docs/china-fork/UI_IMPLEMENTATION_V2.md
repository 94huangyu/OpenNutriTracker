## 能量精度与兼容

- 编辑已有食品以其 kcal 数值初始化局部输入；用户仍可局部选择 kJ。新建默认 kJ；输入偏好不另写数据库，不受全局显示单位切换影响。
- 显示时格式化，未手动改变能量时以原始 kcal 值为准；单位往返不以舍入后的显示值反算。用户手动修改能量才重新读取该单位的输入。保存通过原有营养基准归一化一次。
- 复用 `UnitCalc` 的4.184换算。未改变 Hive 模型、食品/摄入存储单位、备份格式或历史记录，没有迁移。隐含精度保留不代替原有数值有效性校验。
- 14条必要新文案在 en/zh 同步添加，沿用本 Fork 落实中文定稿的局部约定；修改原 kJ 开关中文标题，其他语言未手工编辑；已重新生成本地忽略的翻译输出。
- 新增一个供详情与编辑记录共用的 `FoodPortionSummary`；没有新依赖。上轮无关源码和全部4份冻结设计源稿指纹保持不变。修改前10个运行输入文件快照保存在 `output/ui-v2-before-20261027/`，已为这个目录添加单独的 Git 忽略规则，避免副本误入提交；原文件与回退资产没有删除。
